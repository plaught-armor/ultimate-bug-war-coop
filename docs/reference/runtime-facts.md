- Unattended test runs: `tools/run_pair.sh <tag> [cap_s]` launches host then client, ends on `DONE_PATTERN` or the cap by killing the prefix wineserver, copies `logs/<tag>-{host,client}.log`, reports new crash dumps. Default routes both instances' audio to a PulseAudio null sink (`SOUND=1` keeps it audible); never `-nosound`: it crashes the host in `USTConversationSubsystem::StartStage` after the mission map loads. `DEPLOY=1` deploys `build/dwmapi.dll` after checking 84 exports and KERNEL32-only imports. Every mission map pauses the host on the brief (`WB_Stack_C` `RequestGamePause`, "PRESS ANY KEY"). Unattended pair runs must set `UBWCOOP_AUTODROPSHIP=1` in `HOST_EXTRA_ENV`; it also releases this pause on maps that start on foot (card 032).

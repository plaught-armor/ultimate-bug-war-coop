## Engine facts
- UE5 custom branch `++Aloft+Release_MS18-CL-149768`; IoStore TOC v8; .pak unencrypted.
- Config inis live in `pakchunk0-Windows.pak` (v11, Oodle). List them with `tools/pak/pakls.py`; decode with `tools/iostore/oodec.exe`. Project `DefaultEngine.ini` facts: `bAllowClientSideNavigation=False` (client has no nav system); plain `RecastNavMesh` has `bCanBeMainNavData=False`, Aloft `RecastNavMesh_Small/_Medium/_Large/_Huge/_Gigantic/_GiganticTall` serve paths, baked (`DynamicModifiersOnly`).
- Compiled in: IpNetDriver, Iris, OnlineSubsystemSteam/Null, DemoNetDriver, GAS.
- Game code: `AST*` (game), `AAD*`/`UAD*` (Auroch Digital plugins: ADGASHealth, ADGASWeaponSystem, ADPickups, ADProjectiles, ADPooling, ADLevelStreaming...).
- **No game class implements GetLifetimeReplicatedProps** — zero native replicated state. All co-op state must be added by us.
- Key classes: ASTPlayerCharacter (+Bug/MI/Mech variants), ASTPlayerController, ASTGameplayGameMode, ASTEnemyBase, ASTWarriorBug, ASTAIController, ASTAISpawner, ASTSpawnerBase, ASTLevelObjectiveManager, ASTCheckPointSaveZone, ASTWeapon, ASTPlayerProjectileBase, ASTReplayPlayerController.
- Maps: `/Game/Maps/FED/FED_C1M1` .. `FED_C5M2`, `/Game/Maps/BUG/BUG_C*`, frontend `/Game/Maps/3D_Frontend/3D_Frontend`.

- **The game's own native code replicates nothing** (static scan, 2026-11-03). The game's native classes (`UAD*`, `UST*`, `AAD*`, `AST*`) have 0 of 3629 reflected properties with `CPF_Net` and 0 of 2007 `UFunction`s with `FUNC_Net`. They define no `GetLifetimeReplicatedProps` and no `OnRep_`. The same scan finds 18 `CPF_Net` properties and 34 RPCs on `UAbilitySystemComponent`, so the scan works. Only engine and GAS state replicates: movement, abilities, effects, tags and the attribute set objects, whose attributes have no `CPF_Net`. Everything game-specific (weapon and item inventories, equipped weapon, ammo, health, interaction, objectives) must be carried by the mod. Blueprint classes were not scanned; their content is in IoStore. Scanners: `netprops.py` and `netfuncs.py` in the senior's scratchpad.
- **Replicating a game property:** `Net.AutoRegisterReplicatedProperties` (`UE::Net::bAutoRegisterReplicatedProperties`, RVA 0x08FB8258) is 1. `FRepLayout::InitFromClass` therefore registers any `CPF_Net` property that `GetLifetimeReplicatedProps` left out. Setting `CPF_Net` (0x20) on a property is enough, provided it happens on both machines before `UClass::SetUpRuntimeReplicationData` (0x01431400) caches the class on first network use. There is no RepNotify: the receiver sees the new value without any callback. An object reference replicates only if the object it points to is itself replicated (an actor with `bReplicates`, or a replicated subobject or component).
- **Weapon and inventory layout (static, for a future inventory replication card):** `ASTPlayerCharacterMI` holds `WeaponInventory` at +0xA40 (`USTWeaponInventory`, which derives from `UADWeaponInventory`, then `UADInventory`, then `UActorComponent`) and `AmmunitionInventory` at +0xA48 (`USTAmmunitionInventory`, a `UActorComponent`). `ASTPlayerCharacter` holds `ItemInventory` at +0x860 (`USTItemInventory`, a `UADInventory`). All of them are actor components, so they can replicate through `SetIsReplicated` on a replicated pawn. Their contents are harder. `UADInventory.Items` (+0xD8) is an array of `USTInventoryItem`, which derives from plain `UObject`, so the items replicate only as registered subobjects; setting `CPF_Net` on `Items` alone would send null references. Weapons are `AADWeapon` actors (`ASTWeapon` derives from it). Each has `ASC` (+0x2C0), `WeaponTypeTag` (+0x2C8), `WeaponDefinitionClass` (+0x2D0) and `OwningInventory` (+0x2D8). The native `AADWeapon` constructor (0x04A29FE0) sets only `PrimaryActorTick.bCanEverTick` and creates the weapon ASC, and never sets `bReplicates`. A blueprint default could still set it, so read `bReplicates` on a live weapon before relying on this. Plain values that `CPF_Net` could carry directly: `UADWeaponInventory.LastEquippedWeaponIndex` (+0x124), `USTWeaponInventory.WeaponInventorySlots` (+0x138, an array of `FSTWeaponInventorySlot` with only `WeaponCategory`), `USTItemInventory.EquippedItemIndex` (+0x110), and `USTAmmunitionInventory.MaxAmmoMap` (+0xC8). `AmmoMap` (+0x118) is a TMap, which UE cannot replicate. The likelier route is for each machine to build its own loadout (card 021 step 1) and replicate only the equipped index and the ammo counts through mod RPCs or CPF_Net integers.
- **Actor replication flag (static):** `AActor::bReplicates` is bit 3 of the byte at actor+0x5B (read by `AActor::SetReplicates`, 0x037F42F0). No game code calls `SetReplicates`; all 22 callers are engine code. The native constructors of `AADWeapon` (0x04A29FE0), `ASTWeapon`, `AADProjectile` (0x04A32CA0), `ASTProjectileBase` (0x05226D80), `ASTPlayerProjectileBase` and `ASTEnemyProjectileBase` never write the bit. Projectiles come from a pool (`UADProjectilePooler::SpawnProjectile`, 0x04A363F0). Unless a blueprint default sets `bReplicates`, weapons and projectiles exist only on the machine that spawned them. The client would then see none of the host's or the enemies' projectiles, and the host none of the client's locally predicted ones. Confirm by logging bit 3 of +0x5B on a live weapon and on a spawned projectile, on both machines.
- **Ability net policy (static):** `UGameplayAbility` keeps `ReplicationPolicy` at +0xCE, `InstancingPolicy` at +0xCF, `NetExecutionPolicy` at +0x198 and `NetSecurityPolicy` at +0x199 (one byte each). Neither `UADGameplayAbility` (0x04A0D900) nor `USTWeaponAbility` (0x050B3B40) sets them, so the engine defaults apply unless a blueprint default overrides them. The engine default is `LocalPredicted` (0): the client runs the ability itself and asks the server to run it too. To confirm for a given ability, read +0x198 on the ability's class default object or on its live instance.
- **Mission start (static, 2026-11-04):** the mission brief's `OnStartGame`, `RestartCurrentLevel` 0x050FFC30 and `TransitionToNextLevel` 0x05109550 all call `USTGameInstance::TransitionToLevel(chapter, level, options)` 0x05109340. That calls `USTGameInstance::OpenLevel(FString)` 0x050FA520, which calls `UGameplayStatics::OpenLevel` and reaches `UEngine::Browse` from net mode 0. Details in the card 052 Risks.
- **Interactions (static, 2026-11-04):** `UADInteractorComponent::TickComponent` traces every tick on every copy (no role check), from the scene component at +0x108 out to the range at +0xF8. Its result is cached at +0x100 and used by `Interact`. Details in card 050 Addenda 4 and 5.
- **`SetObjectiveMapPostSave` (static, 2026-11-04):** it rebinds `ObjectiveComplete` on each objective's delegate at +0x38, assigns the map, and destroys its by-value argument. It touches no widget. Details in card 053.

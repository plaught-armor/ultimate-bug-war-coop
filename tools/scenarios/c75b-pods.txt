# Card 075 proof (c75b): a natural pod drop on FED_C4M1 (card 032: the pods dropped about 108 s after both players were
# on foot). The client blocks its own pod mech spawns ("card075: client blocked spawn"); both logs count
# ASTPlayerMechBase actors at 1 Hz ("card075: ... mechs"). The pods sit past a navmesh gap, so the host warps the
# client's server copy (and its own pawn, to watch) next to a pod mech; the client's count then picks up the host's
# replicated mech. The client enters with E, walks 5 s with W and leaves with the E hold. Shots on both sides.
